## Rendering

# Set the appearance of slopes.
# 0: show smooth slopes
# 1: show stair-like slopes (requires stairs mod)
natural_slopes.rendering_mode (Slope rendering mode) int 1 0 1

## Update shape ABM

# Enable or disable the ABM responsible of updating the shape of slopes at regular interval.
natural_slopes.enable_shape_abm (Enable automatic shape update) bool true

# The ABM will run on every block every X seconds.
# The lower the value, the smoother the update will be but it will cost more server resources.
natural_slopes.update_shape_abm_interval (Automatic shape update interval) int 30 0


## Update shape on walk

# Enable or disable shape update when walking on blocks (requires poschangelib mod).
natural_slopes.enable_shape_on_walk (Enable sliding by walking on edges) bool true
